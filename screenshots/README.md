### How to Capture & Place Your Screenshots:
1. Open Windows Snipping Tool (`Win + Shift + S`).
2. Capture each screen accordingly.
3. Save the image with the corresponding filename (e.g., `homepage.png`) directly into this `screenshots/` folder.
